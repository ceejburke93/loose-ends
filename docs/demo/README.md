# Loose Ends demo

- [Video](loose-ends-demo.mp4): 2 minutes 57 seconds, 1920 × 1080, H.264 video and AAC audio.
- [English captions](loose-ends-demo.srt)
- [Narration transcript](narration.txt)
- [Test report](../TEST_REPORT.md)

The video is a narrated walkthrough assembled from actual screenshots captured during an automated owner/recipient browser test on October 20, 2026. Sam, Alex, the repair details, and the technician confirmation are fictional. It is not a continuous screen recording, a physical two-device test, or independent human usability research.

Narration is AI-generated with the **Asa** preset in [Yaps's free text-to-speech tool](https://www.yaps.ai/tools/text-to-speech). The free tool uses Supertonic 3 by Supertone under the BigScience Open RAIL-M license, according to Yaps. We used a preset voice, not a cloned person's voice. The source script is included above. Audio sections were leveled and timed to the captured screens, with captions burned into the MP4 and supplied separately as SRT. No voice model is distributed here. Runtime rendering scripts and downloaded model caches are not application dependencies.

The app is an Alexa+ web simulation. It uses rules-based conversation handling, with no live language model, Alexa device connection, or external technician messaging. The narration voice is part of this video, not the app's Alexa integration.

Access keys and private handoff links are not included. The GitHub file can be downloaded directly; a separate public video-host URL may still be needed for the Devpost submission.
